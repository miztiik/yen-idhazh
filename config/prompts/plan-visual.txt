When source data references follow the item, write "visual" after "summary".

First find the strongest comparison that explains the main story. Start with two actual readings of the same measure on the same basis. Look for an earlier and later value, two places measured the same way, or parts of a stated whole. Readings can be in separate sentences. Check their unit, denominator, and scope. Use the comparable subset; leave other figures out. For a price move, compare the two prices, not percentage changes alongside prices. Do not mix prices per share with total proceeds, even though both are in dollars.

Write "why" first, in one sentence without digits: name that comparison and the takeaway. If no comparable subset would clarify the main story, name what is missing or incompatible and choose "none". A mixture of measures elsewhere in the article does not make the useful subset incompatible.

Choose "type" from the renderer capabilities based on the data, or "none" if no useful chart can be supported. Use these "encodings" (omit unused keys):
- bar or dot: "category" and "quantity", paired in the same order.
- line: "time" and "quantity", paired in date order. Use it for measurements over time, not just two named stages.
- slope: two dates in "time", before and after quantities consecutive for each subject, and one "entity" or "series" per subject.
- scatter or bubble: one "entity", "quantity_x", and "quantity" per point in matching order. Bubble also needs "size".
- pie: "category" and "quantity" for exhaustive, non-overlapping parts, with an independently stated "whole".
- stacked_bar: "series" and "quantity" for exhaustive parts; cite "whole" and copy the common "measure" beside it.
- histogram: "bins" lists comparable individual readings, not precomputed counts.

Use the shown q codes for quantities and the shown d codes for dates. Brackets in the excerpts identify the reading each code points to. For category, entity or series labels, copy short exact words from the source sentence that supports each point; never paraphrase a label. For a chart, give a short factual "title" and a "caption" only if needed for framing, without digits. Use "focus" for the q code of one drawn reading (null for pie). Only composition sets "whole" to a q code; otherwise use null. For "none", use empty encodings and null focus, whole, title and caption.
