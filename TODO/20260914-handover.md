## Environment traps

- **The venv is an editable install pointing at the shared checkout.** Set `$env:PYTHONPATH` to the worktree's `backend` on every command and confirm `idhazh.__file__` resolves inside the worktree.
- **`gh pr merge` from a detached worktree prints `could not determine current branch` and exits 1 having merged.** Read `gh pr view <n> --json state,mergedAt`, never the exit code.
- **`git worktree remove` fails with "Directory not empty"** because of `node_modules` and `test-results`, while still deregistering. Finish with a manual delete and `git worktree prune`.
- **Never wrap `npm --prefix frontend run test:changed` in `gate_lock.py`.** Its `run-checks.ts` takes the same lock and self-deadlocks.
- The collision mapper wants the row id **without** the `#`: `plan-file.md::1a`.
